The companion handbook for this offline Batch learning package. It intentionally has the spirit of CD-ROM software documentation: durable local files, straightforward navigation, no installation, tracking, or internet required.

How to use the course

  1. Open Learn Batch.html in a browser.
  2. Read Start here, then complete Basic, Advanced, and Expert in order.
  3. Copy examples into a test folder, save as .cmd, and run them from Command Prompt.
  4. Use the filter bar in the course to locate a command or concept.
Safety: Batch scripts can alter files, launch programs, and administer Windows. Test on disposable data first, and read /? before adapting destructive or administrative commands.

Pages and sections

  • Documentation.html — this orientation page: authorship, GitHub placeholder, use instructions, layout, and maintenance.
  • Learn Batch.html — the main searchable offline field manual.
  • Start here — creating/running scripts and essential safety.
  • 01 / Basic — syntax, variables, conditions, paths, arguments, and loops.
  • 02 / Advanced — FOR /F, delayed expansion, streams, error levels, and system tooling.
  • 03 / Expert — structure, subroutines, parser escaping, compatibility, auditing.
  • Command index, Recipes, Troubleshooting — fast reference and practical patterns.
Spoiler alert: answers to the exam challenges

These answers are written as a study aid. The course page accepts the first answer form shown for each question, but these alternatives are useful if you want a broader set of acceptable wording.

Exam 01 — Easy

  • E01 — setlocal / local scope / scope
  • E02 — cd / chdir / change directory
  • E03 — %name% / %var% / variable expansion
  • E04 — pause / wait / hold execution
  • E05 — mkdir / md / create directory

Exam 02 — Advanced

  • A01 — @echo off / echo off / silent mode
  • A02 — || / or else / failure chain
  • A03 — %~dp0 / script directory / batch file folder
  • A04 — if exist / check exists / exist check
  • A05 — goto / jump / label jump

Exam 03 — Expert

  • X01 — set /p / prompt input / read input
  • X02 — exit /b / return from batch / subroutine exit
  • X03 — endlocal & set / endlocal and set / return value
  • X04 — setlocal EnableExtensions DisableDelayedExpansion / setlocal enableextensions disabledelayexpansion / extensions off delayed expansion
  • X05 — !var! / delayed expansion variable / block variable

Exam 04 — Extreme

  • T01 — %~1 / first argument / first parameter
  • T02 — for /f / for loop parse / line parser
  • T03 — 2>&1 / merge stderr / stderr to stdout
  • T04 — ^ / caret / escape character
  • T05 — if errorlevel / check exit code / previous command status

Exam 05 — Extreme output questions

  • O01 — 2 / the value after delayed expansion / the updated variable
  • O02 — 1 / the old value because percent expansion happens early / the pre-parse value
  • O03 — outer / the main script value / the unchanged variable
  • O04 — green / the second token / the parsed field
  • O05 — two / the second argument / the shifted parameter

Exam 06 — Extreme command questions

  • C01 — mkdir Lab & cd Lab & type nul > Hello.txt / md Lab & cd Lab & echo. > Hello.txt / mkdir Lab & cd Lab & type nul > Hello.txt
  • C02 — mkdir Root & cd Root & mkdir Work & cd Work & type nul > Hello.txt / md Root & cd Root & md Work & cd Work & echo. > Hello.txt / mkdir Root & cd Root & mkdir Work & cd Work & type nul > Hello.txt
  • C03 — mkdir "My Folder" & cd "My Folder" & type nul > Hello.txt / md "My Folder" & cd "My Folder" & echo. > Hello.txt / mkdir "My Folder" & cd "My Folder" & type nul > Hello.txt
  • C04 — mkdir Data & cd Data & echo ready > Hello.txt / md Data & cd Data & echo ready > Hello.txt / mkdir Data & cd Data & set /p =ready < nul > Hello.txt
  • C05 — mkdir Temp & cd Temp & mkdir Inner & cd Inner & type nul > Hello.txt / md Temp & cd Temp & md Inner & cd Inner & echo. > Hello.txt / mkdir Temp & cd Temp & mkdir Inner & cd Inner & type nul > Hello.txt

Offline design and maintenance

Both documents embed their own styling; the course also embeds its small search filter. They work from a USB drive, archive, or share. Keep the two files together because they link to each other. Before publication, update authorship, GitHub, and licensing; test links after copying the folder; and state the Windows version tested for any new example.
